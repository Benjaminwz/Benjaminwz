## 🎧 [耳機調音台 Headphone Tuner](https://github.com/Benjaminwz/headphone-tuner)

繁體中文的耳機等化器（Windows、Equalizer APO；另有 Android 和網頁版）：

- **任何耳機一鍵校正**：從 AutoEQ 的 6000 多款量測下載，有多份量測的自動算「多源共識」
- **聲音的光線追蹤**：錄音室、音樂廳的殘響是用顯示卡在真實形狀的房間裡模擬出來的（鏡像聲源＋每個聲源 3,355 萬條聲線＋低頻波動模擬），再經過真人頭部量測
- **19 種頭型**：KU100 假人頭＋SADIE II 的 18 位真人，可以直接挑，或用 5 分鐘的配對測驗找最適合你的
- **空間感**：虛擬喇叭、交叉饋送、分離度外掛（把樂器往兩邊拉開）、聲場寬度
- **個人化**：高頻校正測驗、用你自己的歌盲聽找出喜歡的低音高音量
- 50 多種有研究根據的風格，開放原始碼（MIT）
